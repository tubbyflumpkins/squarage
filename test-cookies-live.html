Testing Cookie Consent System

Open this page and click the button to launch the site and test the cookie consent:

Test Checklist:

  1. ✓ Cookie banner appears at the bottom on first visit
  2. ✓ "Accept All" button closes banner and sets all cookies
  3. ✓ "Manage Cookies" opens the preferences modal
  4. ✓ Toggle switches work for each category
  5. ✓ Footer has "Cookie Preferences" link
  6. ✓ Google Analytics and Clarity only load after consent

How to Clear Consent (for retesting):

1. Open Developer Tools (F12)

2. Go to Application/Storage tab

3. Clear localStorage item: squarage_cookie_consent

4. Refresh the page
